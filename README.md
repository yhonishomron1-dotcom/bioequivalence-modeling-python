# Bioequivalence Modeling in Python

A computational pharmaceutical sciences project demonstrating modern approaches to bioequivalence assessment for generic inhaled and nasal drug products using Python.

## Overview

This repository explores computational methods used in pharmaceutical development, biopharmaceutics, and regulatory science. The project includes Python implementations of particle characterization, dissolution modeling, in vitro release testing, respiratory flow simulation, lung deposition analysis, and physiologically based pharmacokinetic (PBPK) modeling.

## Modules

### 1. MDRS Particle Analysis
- Particle segmentation and characterization
- Morphologically Directed Raman Spectroscopy workflows
- Particle size distribution analysis

### 2. Dissolution Profile Modeling
- Dissolution curve fitting
- Drug release kinetics
- Comparison of formulation performance

### 3. IVRT Comparison
- In Vitro Release Testing analysis
- Similarity assessment
- Comparative release profile evaluation

### 4. Respiratory Flow Simulation
- Breathing profile generation
- Inhalation waveform analysis
- Patient variability assessment

### 5. Lung Deposition Modeling
- Regional deposition estimation
- Airway and alveolar distribution analysis
- Inhalation product performance evaluation

### 6. PBPK Modeling
- Physiologically Based Pharmacokinetic simulation
- Drug concentration-time profiles
- Systemic exposure analysis
